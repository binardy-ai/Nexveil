# Nexveil 0.67.15

Кнопка «проверить обновление» больше не прыгает наверх.

## Что было не так

Кнопки «проверить обновление сейчас» и «обновить до …» на странице «Статус» были
обычными формами. После нажатия страница перезагружалась, браузер поднимал её на
самый верх, и раздел «Обновление панели» приходилось искать заново — особенно
неудобно с телефона, где страница длинная.

## Что сделано

- обе кнопки отправляются тихо, без перезагрузки страницы;
- панель сразу перечитывает карточку «Обновление панели» и сама обновляет её,
  пока идёт проверка релиза (до полуминуты) или установка пакета (до двух минут);
- положение прокрутки сохраняется — страница остаётся там, где вы её оставили.

Проверено в настоящем браузере на локальном стенде: адрес страницы не меняется,
прокрутка остаётся на месте (1200 → 1200), карточка после проверки показывает
результат. На роутере 95 версия 0.67.15 установлена, все страницы отвечают 200,
мосты на месте.

## Заодно в этой версии

В 0.67.12–0.67.14 со страницы «Реверс» убрано лишнее: общий переключатель способа
реверса (теперь способ выбирается у каждого моста), тексты-пояснения, карточка
«Как заполнять»; диагностика «что видит панель» убрана под спойлер.

## Установка

Одной командой в терминале роутера (сама выберет формат пакета и загрузчик):

    M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); U=https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E; if command -v wget >/dev/null 2>&1; then wget -q -O /tmp/xraypanel.$E "$U"; else curl -sL -o /tmp/xraypanel.$E "$U"; fi && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

Или из самой панели: «Статус» → «Обновление панели» → «обновить».
