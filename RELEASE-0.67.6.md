# Nexveil 0.67.6

Переезд на новый репозиторий и правильная сборка пакета `apk`.

## Старый адрес репозитория в настройках

Файл `/etc/config/xraypanel` — это настройки, при обновлении он не
перезаписывается. У панелей, поставленных до переезда проекта на новый аккаунт, в
нём оставался прежний адрес (`Petr700/xraypanel`) вместе с прежним токеном
GitHub. Из-за этого проверка обновлений ходила мимо нового репозитория и находила
только старые релизы — новый выпуск панель просто не видела.

Теперь при установке пакета адрес сам меняется на `binardy-ai/Nexveil`, а
ненужный токен убирается: репозиторий публичный, токен для него не нужен. В
консоли установки видно, что именно поправили. Руками ничего делать не надо —
достаточно один раз поставить этот пакет, дальше обновления будут приходить из
нового репозитория.

## Владельцы файлов в пакете apk

Пакет `apk` записывает внутрь владельца файлов. Если собирать его обычным
пользователем, а не от root, то на роутере файлы достаются `nobody` — проверено
живьём: `/www/cgi-bin/xraypanel` становился `nobody:nogroup`. Панель работала, но
это неправильно.

Теперь сборка `apk` не от root запрещена: скрипт останавливается и подсказывает
команду. Порядок сборки описан в README.

## Заодно

- файлы `.apk` в релизе 0.67.5 заменены на собранные от root — те, кто скачает
  его сейчас, получат правильный пакет;
- проверена установка на ImmortalWrt 25.12 (пакеты через `apk`): пакет
  ставится, панель поднимается и открывается, Xray при установке доставляется
  сам, версия и зависимости в карточке пакета совпадают.

## Установка

Одной командой в терминале роутера — она сама определит формат пакета, скачает
из последнего релиза нужный файл и поставит его:

    M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); curl -sL -o /tmp/xraypanel.$E https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

Или скачать файл на компьютер из раздела **Releases** (`.ipk` — для OpenWrt и
ImmortalWrt до 24.10, `.apk` — для 25.12 и новее) и поставить его из
веб-интерфейса роутера: **Система → Менеджер программ → Загрузить пакет**.

Если панель уже стояла и в настройках был старый адрес репозитория, после этой
установки она сама переключится на новый — проверка обновлений и кнопка
«обновить» начнут работать.

Панель в разработке (бета): от версии к версии что-то меняется. Если что-то не
работает или есть идея — пишите в Issues репозитория.
