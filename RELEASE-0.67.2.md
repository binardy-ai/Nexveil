# xraypanel 0.67.2

## Что нового

- **DNS-трафик клиентов теперь виден в таблице трафика.** Раньше в столбце
  «Трафик ↑/↓» был только TCP, и складывалось впечатление, что часть трафика не
  считается. Теперь рядом появляется приписка `DNS 3,8 КБ` — это запросы клиента
  на 53-й порт (UDP и TCP), которые панель перехватывает и отправляет в свой
  резолвер. Значение обновляется и при живом обновлении страницы.
- **Понятная подсказка под таблицей**: считается только TCP — тот трафик,
  который заворачивается в туннель; UDP/443 (HTTP/3) панель намеренно блокирует,
  чтобы трафик не уходил мимо прокси, а DNS показывается отдельно.

Что полезно знать про подсчёт:

- трафик по выходам («Куда идёт трафик») берётся из статистики Xray, а она
  считает всё, включая UDP. Поэтому трафик через Hysteria — а она сама работает
  поверх QUIC — в этой таблице виден полностью;
- DNS показывается только «вверх» (запросы клиента): ответы проходят мимо этой
  цепочки, потому что перехват работает в prerouting;
- счётчик сбрасывается вместе с общим сбросом трафика у клиента.

## Установка

    scp xraypanel_0.67.2_all.ipk root@<IP роутера>:/tmp/
    ssh root@<IP роутера> 'opkg install --force-reinstall /tmp/xraypanel_0.67.2_all.ipk'

Или из панели: «Статус» → «Обновление панели» → «проверить обновление сейчас» →
«обновить».
