# Проверка перед выпуском

Панель ставится на системы двух видов, и проверять надо **обе**:

| Система | Пакетный менеджер | Файл | Пример |
| --- | --- | --- | --- |
| OpenWrt / ImmortalWrt до 24.10 | `opkg` | `.ipk` | роутер 192.168.99.95 (23.05) |
| OpenWrt 25.12 и новее | `apk` | `.apk` | роутер 192.168.99.134 (25.12) |

Почему обе: код один, но упаковка, установка и обновление у систем разные. Из-за
проверки только на 23.05 однажды уехал релиз, в котором кнопка «обновить» на
25.12 не работала вообще.

## Сборка

    APK_BUILD_HOST=root@192.168.99.95 \
    APK_BUILD_SSH_OPTS="-i /home/banx/.ssh/id_xraypanel" \
    bash build-all.sh

Скрипт собирает `.ipk` и `.apk`, проверяет оба и кладёт копии с постоянными
именами в `dist/`. Если `.apk` собрать не от root — владельцы файлов внутри
пакета станут `nobody`, поэтому сборка не от root запрещена.

## Установка и базовые проверки (на каждом роутере)

1. Поставить свежий пакет:

       M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); curl -sL -o /tmp/xraypanel.$E https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

2. Версия на роутере совпадает с выпущенной:

       cat /etc/xraypanel/version

3. Страницы открываются (везде код 200):

       for p in status servers rules proxy bridges settings; do
         printf '%s: ' "$p"
         curl -s -o /dev/null -w '%{http_code}\n' "http://127.0.0.1/cgi-bin/xraypanel?page=$p"
       done

4. Xray работает, конфиг читается:

       pgrep -f xray >/dev/null && echo "xray работает"
       xray run -test -c /etc/xray/config.json 2>&1 | tail -1

5. На 25.12 файлы после установки принадлежат `root`, а не `nobody`:

       ls -l /www/cgi-bin/xraypanel /usr/lib/xraypanel/lib.sh

## Проверка обновления (обязательно, если трогали обновление или установку)

1. Что панель видит правильный файл и размер:

       sh /usr/lib/xraypanel/update-check.sh
       cat /etc/xraypanel/update.info

   В `url` должен быть файл нужного формата (`.ipk` на opkg, `.apk` на apk), а
   `size` — совпадать с размером этого файла в релизе.

2. Кнопка «обновить» работает: поставить на роутер предыдущую версию, открыть
   «Статус» → «обновить» (или выполнить `sh /usr/lib/xraypanel/update-install.sh`)
   и убедиться, что версия поднялась, а в журнале нет слова «не похож»:

       tail -5 /etc/xraypanel/update-install.log

3. Если репозиторий публичный, поле «токен GitHub» в настройках должно быть
   пустым — со старым токеном панель уходила в «приватный режим».

## Что ещё смотреть после правок

- после обновления подписки названия серверов и флаги на месте;
- применение конфига проходит без ошибок (кнопка на «Статусе»);
- перезагрузка роутера: панель и правила поднимаются сами.
