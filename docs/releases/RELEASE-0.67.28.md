# Nexveil 0.67.28

Доработка серверов **AmneziaWG** и сборки пакетов. Всё, что появилось после
0.67.23.

## AmneziaWG

- **Keep alive настраивается.** В форме сервера появилось поле «Keep alive, сек
  (клиент → сервер)». Пусто — как у клиентов Amnezia по умолчанию, 25 секунд;
  `0` — не отправлять вовсе. Раньше значение было жёстко прописано. Для обычного
  WireGuard это же поле пишется в выход xray как `keepAlive` (пусто — как было,
  без keepalive).
- **«Разрешить входящие через туннель»** — новый переключатель у сервера
  AmneziaWG. По умолчанию firewall роутера отбрасывает всё, что приходит в
  туннель снаружи, поэтому с телефона или из другого узла нельзя было открыть
  панель, LuCI или SSH роутера. При включении панель заводит для интерфейса
  отдельную зону firewall с разрешённым входом (и убирает её, если сервер
  выключили или удалили).
- **Маршрут до сети туннеля** панель ставит сама (10.0.0.0/24): без него ответ
  другому узлу туннеля уходил по обычному маршруту в интернет и терялся.
- **Запуск клиента на 25.12 починен.** На части сборок (проверено на
  amneziawg-go 3.1 в ImmortalWrt 25.12) запуск через `start-stop-daemon`
  завершался сразу, и интерфейс не поднимался — теперь сначала `setsid`, а
  `start-stop-daemon` остаётся запасным. Если в системе есть модуль ядра
  AmneziaWG, панель использует его (создаёт интерфейс сама), иначе — клиент в
  пользовательском режиме.
- **Проверка сервера стала честнее.** Сначала панель пингует сам сервер внутри
  туннеля (обычно 10.0.0.1) — это проверка туннеля, она не зависит от того,
  отвечает ли кто-то в интернете на ping. Затем — обычный тестовый адрес. Если
  ping не проходит, но рукопожатие свежее, панель показывает «работает» и в
  подсказке поясняет: рукопожатие было N секунд назад, ICMP фильтруется.

## Сборка и установка

- `.apk`: postinst подключается и как **post-upgrade** — при обновлении на
  системах с apk (25.12) теперь включается автозапуск служб. Раньше postinst при
  обновлении не выполнялся вовсе.
- `build-all.sh`: исправлен путь к `apk.static` при сборке на роутере (скрипт
  искал файл, которого там нет) и распаковка `apk-tools-static` — на busybox-tar
  нет ключа `--ignore-zeros`, добавлен запасной способ через `apk extract`.

## Установка

Одна команда, сама выберет формат пакета (`.ipk` или `.apk`) и загрузчик:

```
M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); U=https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E; if command -v wget >/dev/null 2>&1; then wget -q -O /tmp/xraypanel.$E "$U"; else curl -sL -o /tmp/xraypanel.$E "$U"; fi && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }
```

Отдельно для систем с `opkg` (до 24.10):

```
wget -q -O /tmp/xraypanel.ipk https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.ipk && opkg install --force-reinstall /tmp/xraypanel.ipk
```

Отдельно для систем с `apk` (25.12 и новее):

```
wget -q -O /tmp/xraypanel.apk https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.apk && apk add --allow-untrusted /tmp/xraypanel.apk
```
