# xraypanel 0.67.1

Небольшое, но полезное обновление.

## Что нового

- **обфускация Hysteria 2 (salamander)**: если сервер её требует, панель теперь
  умеет её использовать. В ссылке это `obfs=salamander&obfs-password=…` — панель
  читает эти параметры, показывает в форме сервера поля «Обфускация» и «Пароль
  обфускации» и пишет в конфиг `finalmask.udp` с маской `salamander`.
  Если обфускации нет, конфиг остаётся прежним.
- исправления, вошедшие в панель по ходу проверок:
  - Hysteria: в конфиг добавлен TLS (без него xray отвечал «tls config is nil»);
  - WireGuard: добавлен `noKernelTun` (без него xray падал на `CreateTUN("wg0")`
    и вместе с ним не поднималась сама служба);
  - подписки: принимаются ссылки `vmess://`, `trojan://` и `wireguard://`
    (раньше они молча пропускались);
  - форма сервера: поля «Тег выхода», «Адрес» и «Порт» больше не пропадают при
    выборе протокола, кроме VLESS; UUID показывается у VLESS и VMess, SNI — у
    VLESS, VMess, Trojan и Hysteria;
  - из методов Shadowsocks убран `none` — xray его не знает.

## Установка

    scp xraypanel_0.67.1_all.ipk root@<IP роутера>:/tmp/
    ssh root@<IP роутера> 'opkg install --force-reinstall /tmp/xraypanel_0.67.1_all.ipk'

Или из самой панели: «Статус» → «Обновление панели» → «проверить обновление
сейчас» → «обновить».
