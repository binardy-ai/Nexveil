# xraypanel 0.67.0

Первая публичная версия веб-панели для Xray на роутерах OpenWrt.
Одна CGI-страница и shell-скрипты: ни Python, ни PHP, ни Node на роутере не
нужны. Работает на OpenWrt 21.02 и новее, на ImmortalWrt и на сборках на их
основе (проверено на ImmortalWrt 23.05.4, x86_64).

## Установка

    scp xraypanel_0.67.0_all.ipk root@<IP роутера>:/tmp/
    ssh root@<IP роутера> 'opkg install /tmp/xraypanel_0.67.0_all.ipk'

Панель открывается по адресу `http://<IP роутера>/cgi-bin/xraypanel`.
Нужен установленный `xray-core` и CGI в `uhttpd` (в OpenWrt он уже включён).

## Что нового в 0.67.0

- **самообновление панели**: панель сама проверяет новый релиз на GitHub
  (раз в сутки и при открытии страницы «Статус»), показывает «доступна версия X»,
  по кнопке показывает список изменений и ставит обновление одним нажатием —
  настройки, серверы и правила при этом не трогаются;
- **оба способа реверс-мостов**: старый (по домену, `reverse.bridges`) и новый
  (VLESS Reverse Proxy по тегу). Панель определяет, что умеет установленный
  бинарник Xray, пишет в конфиг только поддерживаемый способ и подсказывает,
  какая сборка нужна для какого способа. Важно: для нового способа версии Xray
  на роутере и на портале должны быть совместимы;
- **готовые списки разбираются на месте**: домены — из `geosite.dat`, адреса —
  из `geoip.dat`. По ним панель проверяет условия правил точно, поэтому видно,
  какое правило и какая запись набора реально поймали трафик;
- **живые лампочки** у правил и записей наборов: вспышка и плавное затухание за
  30 секунд, состояние считается «как у Xray» — с учётом порядка правил;
- **подбор правила по домену**: вводите домен — панель показывает, в каких
  готовых списках он есть, какое правило его поймает и что перекрыто выше;
- **обновление баз** `geosite`/`geoip` из интернета (Loyalsoldier, v2fly,
  runetofreedom) вручную или по расписанию, со сводкой и журналами;
- прозрачный режим (клиенты, вся сеть или сам роутер) с автооткатом, если не
  подтвердить правила; DNS: перехват в туннель, резолверы, блокировка DoH/DoT;
- статистика: трафик по клиентам, по выходам и по правилам, история
  переключений между серверами;
- темы оформления, звук нажатий, удобные таблицы для телефона.

## Что умеет панель (кратко)

- выходы: VLESS + Reality, VLESS + WebSocket, Shadowsocks, Hysteria 2 —
  добавление, правка, выключение, проверка задержки, автовыбор по пингу,
  подписки;
- маршрутизация: правила «кто идёт → куда → через что» и наборы адресов и
  доменов (IP/сеть, домен с поддоменами, точный домен, слово, шаблон, готовые
  списки доменов и адресов);
- применение конфига через проверку `xray run -test`, бэкапы и откат;
- пароль на вход в панель (необязательно).
