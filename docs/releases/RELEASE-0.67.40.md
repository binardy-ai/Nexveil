# Nexveil 0.67.40

Крупное обновление после 0.67.28: добавлены **Mieru** и **NaiveProxy**, у
клиентских протоколов появились свои вкладки, проверки серверов стали честными,
а подписки — универсальными.

## Серверы через свои пакеты: Mieru, NaiveProxy, AmneziaWG

- В меню появились вкладки **AmneziaWG**, **Mieru** и **Naive** — на каждой свой
  список серверов (имя, адрес, проверка, кнопки изменить / проверить / выключить
  / удалить) и кнопка добавления, которая открывает форму с уже выбранным
  протоколом (выбор протокола внутри этих вкладок не показывается, на странице
  «Серверы» он остался).
- На каждой из трёх вкладок — постоянная кнопка установки клиента, короткое
  пояснение, зачем он нужен, пометка, что это установка **системных пакетов** на
  роутер, и те же шаги командами (`opkg`/`apk` для AmneziaWG и Naive, архив с
  GitHub для Mieru) с кнопкой «копировать». Журнал установки клиента AmneziaWG
  переехал на свою вкладку.
- **Mieru**: клиент на роутере поднимает локальный SOCKS, xray ходит через него
  как через обычный сервер; в таблице видна готовая ссылка `mierus://` для
  телефона или другого роутера. В инструкции отдельно сказано про синхронизацию
  времени (ключ Mieru считается по системному времени, допуск 4 минуты).
- **NaiveProxy**: тот же принцип (клиент на роутере + локальный SOCKS), важное
  отличие — клиент обязательно проверяет сертификат сервера, поэтому нужен
  настоящий сертификат и домен. Кнопка установки сначала берёт пакет
  `naiveproxy` из фидов системы (правильная сборка под musl), затем пробует
  готовый файл из `/etc/xraypanel/versions` или `/tmp`, и только в последнюю
  очередь — архив с GitHub (он собран под glibc и на роутере не запускается).
  Панель проверяет не «есть ли файл», а «запускается ли клиент», и честно
  предупреждает, если лежит нерабочая сборка.
- Клиенты Mieru и Naive поднимаются автоматически (автозапуск + hotplug), а
  «осиротевшие» клиенты от удалённых серверов больше не копятся в памяти.

## Подписки

- В форме подписки на «Серверах» появился выбор протокола: **«всё сразу»
  (обычные + Mieru + Naive)**, «только Mieru», «только Naive». В режиме «всё
  сразу» каждая ссылка разбирается по своему типу, поэтому одна подписка может
  содержать и vless/ss/hysteria, и `mierus://`, и Naive-ссылки.
- Понимаем «нативную HTTPS-схему» Naive, которой пользуются другие панели:
  `https://<base64(логин:пароль@адрес:порт)>?remarks=…`.
- Разбор подписок стал терпимее к формату ответа: обычный список, всё в одну
  строку, base64, **HTML-страница** (например, страница «mieru connection») и
  **Clash-YAML** — из них панель сама достаёт ссылки; заодно раскодируются
  HTML-мнемоники (`&amp;`). Для формата `?format=mieru` панель автоматически
  перезапрашивает адрес как `?format=mierus`.
- Подписки Mieru снова можно заводить, они видны в общем списке с пометкой
  «(Mieru)», и у них заполняются «Узлов» и «Обновлено».

## Проверки серверов

- Цифры в столбце «Проверка (прокси)» были завышены в разы. Причина: запрос
  делался через `wget`, а на OpenWrt это `uclient-fetch`, который сам по себе
  тратит 600–900 мс даже без прокси, плюс в замер попадал запуск процесса.
  Теперь запрос делает `curl`, а время берётся у него самого (`time_total`).
  Для примера: Naive показывал 820 мс, а стал 55 мс при том же сервере.
- Проверка AmneziaWG больше не пинг: она делает настоящий запрос через
  интерфейс туннеля тем же тестовым адресом, что и остальные протоколы. Пинг
  остался вторым шагом — для подсказки, если запрос не прошёл.

## Прочее

- Вставка ссылки на сервер переехала в форму создания сервера (как вставка
  `.conf` у AmneziaWG): вставляете ссылку — панель разбирает её, переключает
  протокол и заполняет поля. Поддерживаются `vless://`, `ss://`, `hysteria2://`,
  `trojan://`, `vmess://`, `mierus://`, `naive+https://`, `naive+quic://`.
  Если вставить адрес страницы (`http://…`, `https://…`), панель подскажет, что
  это адрес подписки.
- Подписки всех протоколов живут на странице «Серверы».
- Для AmneziaWG убрана подсказка про реверс-мосты (эти серверы в мостах не
  участвуют), в форме Naive больше не показывается выбор протокола.

Пакеты: `xraypanel_0.67.40_all.ipk` (opkg, до 24.10) и
`xraypanel_0.67.40_all.apk` (apk, 25.12+).
