# Nexveil 0.67.18

Реверс-мосты: понятнее настройка и починка нового способа. Плюс несколько правок
по интерфейсу.

## Новый способ реверса теперь работает, если мостов несколько

Если на **одном** сервере-выходе висит несколько мостов с новым способом
(VLESS Reverse Proxy по тегу), панель писала пометку `"reverse":{"tag":…}` только
для первого. У второго моста в конфиге было правило маршрутизации по его тегу, но
самой пометки реверса не было — туннель не поднимался. Так работает сам xray:
одна пометка `reverse` на выход, вторая игнорируется.

Теперь на каждый следующий мост панель пишет **копию выхода** — тот же сервер, но
отдельный тег (`<тег>-rev2`, `-rev3`, …) со своей пометкой реверса. Копии не
попадают в балансировщик и в проверку пинга: это не новые серверы, а «входы»
туннелей.

## Общий переключатель способа реверса убран

Раньше был «общий способ реверса», а у моста можно было выбрать «как у роутера».
Из-за этого мост со старым способом молча не попадал в конфиг, когда общий стоял
«новый». Теперь способ задаётся **у каждого моста**: «старый (по домену)» или
«новый (по тегу)». При обновлении старое общее значение переносится в мосты, где
способ не был задан, — поведение не меняется, настраивать стало очевиднее.

Если выбранного способа нет в установленной сборке xray, это видно в списке
мостов: «в конфиг не попадёт» — раньше такой мост исчезал из конфига молча.

## Кнопка «проверить обновление» больше не подбрасывает страницу наверх

Причина была в адресе страницы: если панель открыта **без** `page=` в адресе
(просто `http://<роутер>/cgi-bin/xraypanel` — так её обычно и открывают), сервер
показывает «Статус», а браузерный код считал текущую страницу пустой. После
нажатия «проверить обновление» панель считала ответ переходом на другую страницу
и перезагружала её — браузер поднимал страницу наверх. Теперь пустой `page`
считается «Статусом»: перехода нет, прокрутка остаётся на месте. Плюс панель
снимает фокус и сохраняет позицию прокрутки при перерисовке карточек.

## Мелкие правки на странице «Реверс»

- убраны пояснительные тексты и карточка «Как заполнять»;
- диагностика «что видит панель» убрана под спойлер.

## Установка

Одной командой в терминале роутера (сама выберет формат пакета и загрузчик):

    M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); U=https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E; if command -v wget >/dev/null 2>&1; then wget -q -O /tmp/xraypanel.$E "$U"; else curl -sL -o /tmp/xraypanel.$E "$U"; fi && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

Или из самой панели: «Статус» → «Обновление панели» → «обновить».

Панель в разработке (бета): от версии к версии что-то меняется. Если что-то не
работает или есть идея — пишите в Issues репозитория.
