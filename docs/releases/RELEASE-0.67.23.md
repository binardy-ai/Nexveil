# Nexveil 0.67.23

Главное в этом выпуске — **серверы AmneziaWG**. Кроме них вошли правки,
которые были сделаны после 0.67.18 (показ различий конфига, кнопки применения,
подписи про версии xray).

## AmneziaWG (WireGuard с маскировкой)

Ядро xray AmneziaWG не понимает (в нём обычный WireGuard), поэтому сделано
иначе: клиент поднимается отдельным интерфейсом на роутере, а xray выпускает в
него трафик. Для правил маршрутизации такой сервер выглядит как обычный выход.

- новый тип сервера **AmneziaWG** с полями ключей, адреса клиента, AllowedIPs,
  MTU и параметров маскировки `Jc/Jmin/Jmax`, `S1–S4`, `H1–H4`, `I1–I5`
  (последние пять — для конфигов AmneziaWG 3.x);
- **вставка готового конфига**: вставляете текст `.conf` из приложения Amnezia
  и нажимаете «Заполнить поля из конфига» — ключи, адрес, MTU, параметры
  маскировки и `Endpoint` (разбирается на адрес и порт) подставляются сами;
- панель **сама поднимает интерфейс** при сохранении сервера, гасит его при
  удалении и выключении, восстанавливает после перезагрузки роутера и
  перепроверяет при переподключении провайдера;
- **проверка** такого сервера идёт внутри туннеля: панель смотрит рукопожатие и
  делает настоящий запрос. В столбце «Проверка» видно миллисекунды, а причина
  отказа — в подсказке при наведении;
- **установка клиента из панели**: кнопка «Установить клиент AmneziaWG» на
  странице «Серверы». Панель сама определяет версию системы, цель и
  архитектуру, скачивает подходящий набор (для ImmortalWrt 23.05.4 берёт
  сборку 23.05.6), ставит `amneziawg-tools` и `amneziawg-go`, при необходимости
  доставляет `unzip` и `kmod-tun`. Модуль ядра не нужен — клиент работает в
  пользовательском режиме. Ход установки виден тут же на странице.

## Правки после 0.67.18

- различия конфига показываются целиком, а не обрезанной строкой (0.67.19);
- верхняя кнопка «применить конфиг» на «Маршрутах» сохраняет строки, кнопка в
  шапке не исчезает после применения, о неудаче панель говорит словами, у
  второй кнопки на «Конфиге» появился общий вид (0.67.20);
- подписи про версии xray сведены к одной формулировке: «старый — по домену
  (xray до 26.4.17 включительно)», «новый — VLESS Reverse Proxy по тегу (xray
  25.9.11 и новее)» (0.67.20);
- при обновлении пакета на системах с `apk` теперь выполняется post-upgrade,
  поэтому автозапуск AmneziaWG включается и при обновлении, а не только при
  установке «с нуля» (0.67.23).

## Что нужно для AmneziaWG

Клиент ставится кнопкой из панели, вручную ничего скачивать не надо. Если
панель не может достать набор из интернета, положите файлы `amneziawg-go` и
`amneziawg-tools` в `/etc/xraypanel/versions` или `/tmp` — кнопка поставит их
оттуда.

## Проверено

Сборка проверена на двух линиях:

| Система | Роутер | Результат |
| --- | --- | --- |
| ImmortalWrt 23.05.4 (opkg) | 192.168.99.95 | панель 0.67.23, интерфейс AmneziaWG поднят, рукопожатие идёт, проверка 32 мс, все страницы отвечают |
| ImmortalWrt 25.12.0 (apk) | 192.168.99.134 | панель 0.67.23, автозапуск AmneziaWG создан при обновлении, настройки панели сохранились, все страницы отвечают |

Сквозная проверка: трафик, выпущенный xray через сервер AmneziaWG, выходит в
интернет с адреса сервера, а не домашнего провайдера.

## Установка

Одна команда, сама выберет формат пакета (`.ipk` или `.apk`) и загрузчик:

```
M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); U=https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E; if command -v wget >/dev/null 2>&1; then wget -q -O /tmp/xraypanel.$E "$U"; else curl -sL -o /tmp/xraypanel.$E "$U"; fi && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }
```

Отдельно для систем с `opkg` (до 24.10):

```
wget -q -O /tmp/xraypanel.ipk https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.ipk && opkg install --force-reinstall /tmp/xraypanel.ipk
```

Отдельно для систем с `apk` (25.12 и новее):

```
wget -q -O /tmp/xraypanel.apk https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.apk && apk add --allow-untrusted /tmp/xraypanel.apk
```

В релизе четыре файла: `xraypanel_all.ipk`, `xraypanel_all.apk` (постоянные
имена, на них смотрит ссылка `releases/latest`) и такие же с номером версии —
`xraypanel_0.67.23_all.ipk`, `xraypanel_0.67.23_all.apk`.
