# Nexveil 0.67.10

Настройки применяются сразу, и убраны две подсказки.

## Язык, звук и громкость видны сразу после сохранения

Раньше после сохранения настроек новое значение языка или звука кнопок
появлялось только после перезагрузки страницы: браузер берёт оформление, язык и
звук из самой страницы, а панель перечитывала её только при смене темы.

Теперь поля «Оформление панели», «Язык панели», «Звук кнопок» и «Громкость»
запоминают своё значение до сохранения, и если хоть одно из них изменилось —
панель сразу перечитывает страницу. Если меняли что-то другое (интервал
подписок, репозиторий обновлений и так далее), перезагрузки по-прежнему нет — это
по-прежнему тихое сохранение.

## Убраны две подсказки

- на странице **«Реверс»**, под блоком «Проверка: что видит панель» — текст
  «Если тут написано «таблица соединений: НЕТ» или пусто в «есть команды»…»;
- на странице **«Прокси»**, в блоке выбора клиентов — предупреждение «В
  настройках остались адреса, которых сейчас нет среди подключённых…».

У второй подсказки убран только текст: адреса, которых сейчас нет среди
подключённых, как и раньше, вычищаются при сохранении — просто панель об этом
больше не сообщает.

## Установка

Одной командой в терминале роутера (сама выберет формат пакета и загрузчик):

    M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); U=https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E; if command -v wget >/dev/null 2>&1; then wget -q -O /tmp/xraypanel.$E "$U"; else curl -sL -o /tmp/xraypanel.$E "$U"; fi && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

Или из самой панели: «Статус» → «Обновление панели» → «обновить».

Панель в разработке (бета): от версии к версии что-то меняется. Если что-то не
работает или есть идея — пишите в Issues репозитория.
