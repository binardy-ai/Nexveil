# Nexveil 0.67.8

Правки по четырём багам, которые нашлись на роутере с OpenWrt 25.12. Код панели
на 23.05 и 25.12 одинаковый, поэтому все четыре исправления сделаны в общем коде
и касаются обеих систем.

## Вторая подписка затирала первую

Если при добавлении подписки не заполнять имя, панель использовала имя раздела
`sub`. Вторая подписка без имени попадала в тот же раздел и перезаписывала адрес
первой. Теперь при пустом имени панель подбирает свободное: `sub1`, `sub2` и
дальше по порядку. Подписки больше не затирают друг друга.

## Правка моста добавляла новый мост вместо изменения

Если мост создавали, не заполнив «Имя раздела», раздел получался безымянным
(`@bridge[1]`) — а такие имена панель не признавала: вместо правки создавался
ещё один безымянный раздел. Теперь панель умеет работать и с уже существующими
безымянными разделами: правит и удаляет именно их, копий больше не появляется.
Новые разделы без имени тоже больше не создаются — им даётся обычное имя
(`bridge1`, `server1`, `rule1`).

## Таблицы не обновлялись без перезагрузки страницы

После сохранения панель перерисовывала не все блоки: таблица серверов вместе со
списком подписок и таблица мостов оставались старыми до перезагрузки. Теперь
обе перерисовываются сразу после действия.

## Кнопка пуск/пауза у моста не меняла вид

Живое обновление меняло только текст состояния, а значок кнопки (▶/⏸) оставался
прежним. Теперь вместе с состоянием обновляются значок, подсказка и цвет кнопки.

## Установка

Одной командой в терминале роутера (сама выберет формат пакета и загрузчик):

    M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); U=https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E; if command -v wget >/dev/null 2>&1; then wget -q -O /tmp/xraypanel.$E "$U"; else curl -sL -o /tmp/xraypanel.$E "$U"; fi && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

Или из самой панели: «Статус» → «Обновление панели» → «обновить».

Панель в разработке (бета): от версии к версии что-то меняется. Если что-то не
работает или есть идея — пишите в Issues репозитория.
