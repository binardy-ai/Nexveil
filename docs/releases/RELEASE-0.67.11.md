# Nexveil 0.67.11

Перетаскивание правил пальцем — как в мобильных списках.

## Что было не так

Правила было тяжело двигать: на телефоне — «долго срабатывает или
малочувствителен», мышкой — тоже неудобно. Причины были такие:

- удержание было ровно 1 секунда;
- удержание сбрасывалось при **любом** движении пальца, даже на пару пикселей —
  а палец на телефоне всегда чуть дрожит, поэтому до конца секунды дело почти не
  доходило;
- панель сразу блокировала прокрутку, если жест начинался на строке правила;
- не было автопрокрутки: правило через полсписка было не перетащить;
- ручка «⠿» была около 25 пикселей — попасть пальцем тяжело.

## Что сделано

- **Зажал где угодно — и тащишь.** Удержание 200 мс вместо секунды, отмена
  только при сдвиге пальца больше 12 пикселей (мелкая дрожь не мешает);
- при подхвате строка подсвечивается, приподнимается и даёт короткую вибрацию —
  сразу видно, что «поймал»;
- пока тащишь, список сам подкручивается у верхнего и нижнего края экрана;
- пока тащишь, прокрутка страницы глушится, чтобы браузер не «отбирал» жест и
  строка не падала на место;
- за ручку «⠿» можно тянуть **сразу, без удержания**, и сама ручка стала крупнее
  (44×44 — нормальная зона для пальца);
- обычный тап по строке ничего не двигает — можно спокойно пользоваться полями и
  кнопками в строке.

Порядок, как и раньше, сохраняется тихо, без кнопки «применить».

## Установка

Одной командой в терминале роутера (сама выберет формат пакета и загрузчик):

    M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); U=https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E; if command -v wget >/dev/null 2>&1; then wget -q -O /tmp/xraypanel.$E "$U"; else curl -sL -o /tmp/xraypanel.$E "$U"; fi && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

Или из самой панели: «Статус» → «Обновление панели» → «обновить».

Панель в разработке (бета): от версии к версии что-то меняется. Если что-то не
работает или есть идея — пишите в Issues репозитория.
