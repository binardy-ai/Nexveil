# Nexveil 0.67.5

Флаги стран в названиях серверов из подписки.

## Что было не так

В ссылках подписки название узла идёт после решётки и часто содержит флаг страны
(например `%F0%9F%87%A9%F0%9F%87%AAhisteria-WRT` — это 🇩🇪). Панель его
выбрасывала: из названия делался технический тег, где разрешены только латиница,
цифры, точка и дефис. В итоге в таблице оставалось `histeria-WRT` без флага, и по
списку было непонятно, где какой сервер.

## Что сделано

- при добавлении сервера из подписки (и при вставке ссылки `vless://` вручную)
  исходное название сохраняется отдельно — в поле `title`. В конфиг xray оно не
  попадает: там по-прежнему технический тег, поэтому правила, статистика,
  реверс-мосты и уже сохранённые настройки продолжают работать как раньше;
- в таблице «Серверы» в столбце «Имя» теперь видно название из подписки — с
  флагом и русскими буквами, если они есть. Полный текст по-прежнему виден при
  наведении мышки;
- в выпадающих списках «через что выходим» (правила, прозрачный режим, DNS,
  реверс-мосты) сервер подписан так же: «сервер 🇩🇪Germ_Vless». Технический тег
  в скобках добавляется только тогда, когда он действительно отличается от
  названия;
- в статистике по выходам и в таблице мостов показывается то же название;
- если тег сервера переименовали в форме руками, сохранённое название стирается —
  чтобы не осталось старой подписи.

## Как получить флаги

Ничего пересоздавать не нужно: обновите пакет и нажмите «обновить» у подписки на
странице «Серверы». Флаги появятся и у серверов, которые были добавлены раньше.

## Замечания

- В Windows браузеры не рисуют флажки стран (показывают буквы `DE`) — это
  особенность самой системы, а не панели. На телефоне и Linux видно как надо.
- Название берётся из подписки как есть. Если провайдер добавляет в него хвост
  вроде `?serverDescription=...`, он тоже попадёт в подпись — это отдаёт
  подписка, а не панель.

## Установка

Одной командой в терминале роутера — она сама определит формат пакета, скачает
из последнего релиза нужный файл и поставит его:

    M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); curl -sL -o /tmp/xraypanel.$E https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

Или скачать файл на компьютер из раздела **Releases** (`.ipk` — для OpenWrt и
ImmortalWrt до 24.10, `.apk` — для 25.12 и новее) и поставить его из
веб-интерфейса роутера: **Система → Менеджер программ → Загрузить пакет**.

Обновить панель можно и прямо из неё: «Статус» → «Обновление панели» →
«проверить обновление сейчас» → «обновить». Настройки, серверы и правила при
установке и обновлении не трогаются.

Панель в разработке (бета): от версии к версии что-то меняется. Если что-то не
работает или есть идея — пишите в Issues репозитория.
