# Nexveil 0.67.9

Доработка к 0.67.8: строка подписки в списке обновляется сразу.

## Что было не так

В 0.67.8 таблицы серверов и мостов начали обновляться без перезагрузки страницы,
но список подписок остался в стороне: при добавлении или удалении подписки
серверы появлялись и исчезали правильно, а сама строка подписки не менялась —
её было видно только после F5.

Причина в разметке: список подписок лежит в отдельной карточке, а обновлялся
только блок с таблицей серверов (`#servers-box`).

## Что сделано

- список подписок вынесен в свой блок (`#subs-box`) и получил отдельную точку
  выдачи (`page=subs_table`), как это уже сделано для таблицы серверов;
- после добавления, удаления и обновления подписки панель перерисовывает этот
  блок сразу — строка появляется и исчезает без перезагрузки страницы.

## Установка

Одной командой в терминале роутера (сама выберет формат пакета и загрузчик):

    M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); U=https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E; if command -v wget >/dev/null 2>&1; then wget -q -O /tmp/xraypanel.$E "$U"; else curl -sL -o /tmp/xraypanel.$E "$U"; fi && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

Или из самой панели: «Статус» → «Обновление панели» → «обновить».

Панель в разработке (бета): от версии к версии что-то меняется. Если что-то не
работает или есть идея — пишите в Issues репозитория.
