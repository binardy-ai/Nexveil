# Nexveil 0.67.12

Общий способ реверса убран — способ выбирается у каждого моста.

## Зачем

Раньше был «общий способ реверса» (кнопка на странице «Реверс»), а у каждого
моста можно было выбрать «как у роутера». На этом мы и споткнулись: у моста стоял
**старый** способ, а общий — **новый**, и панель вообще не писала блок старого
реверса (`reverse.bridges`), потому что условие требовало «общий = старый». Мост
молча не регистрировался на портале, и связи не было — при том что в самом мосте
всё было настроено верно.

## Что изменилось

- кнопка «Сменить общий способ» и сам общий способ убраны: способ реверса
  задаётся **у каждого моста** в его форме — «старый (по домену)» или
  «новый (по тегу)». У нового моста по умолчанию стоит новый способ;
- если у моста выбран способ, которого нет в установленной сборке xray, это
  прямо видно в списке мостов: «в конфиг не попадёт», с подсказкой. Раньше такой
  мост исчезал из конфига молча;
- блок старого реверса пишется всегда, когда есть хотя бы один мост со старым
  способом и бинарник xray его понимает — независимо от других мостов;
- при обновлении панели способ из старой настройки один раз переносится в те
  мосты, где он не был задан, поэтому после установки ничего не меняется —
  просто настраивать стало очевиднее.

## Установка

Одной командой в терминале роутера (сама выберет формат пакета и загрузчик):

    M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); U=https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E; if command -v wget >/dev/null 2>&1; then wget -q -O /tmp/xraypanel.$E "$U"; else curl -sL -o /tmp/xraypanel.$E "$U"; fi && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

Или из самой панели: «Статус» → «Обновление панели» → «обновить».

Панель в разработке (бета): от версии к версии что-то меняется. Если что-то не
работает или есть идея — пишите в Issues репозитория.
