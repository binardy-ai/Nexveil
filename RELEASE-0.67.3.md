# xraypanel 0.67.3

## Что исправлено

- **панель больше не просит применить конфиг «просто так».** Раньше при нажатии
  кнопок на «Маршрутах» могло появляться сообщение «Файл на роутере отличается от
  текущих настроек», а в списке строк — `head: standard output: Broken pipe`.
  Причина: вывод генератора конфига ограничивался через `head`, и когда `head`
  закрывал трубу раньше, его сообщение попадало в текст собранного конфига. Файл
  на роутере такой строки не содержал — панель видела «расхождение» и требовала
  применить конфиг заново.

  Теперь: вывод ограничивает сам `awk` (без `head`), первый DNS-резолвер берётся
  через `sed` (он читает поток до конца), страница «Конфиг» не подмешивает
  сообщения утилит в текст конфига — при настоящем сбое показывается отдельная
  плашка «Конфиг не собирается» с причиной. Плюс в сравнении с файлом
  игнорируются строки-сообщения вида `head: …`, `sed: …`, `awk: …`: строками
  JSON-конфига они быть не могут.

## Установка

    scp xraypanel_0.67.3_all.ipk root@<IP роутера>:/tmp/
    ssh root@<IP роутера> 'opkg install --force-reinstall /tmp/xraypanel_0.67.3_all.ipk'

Или из панели: «Статус» → «Обновление панели» → «проверить обновление сейчас» →
«обновить».
