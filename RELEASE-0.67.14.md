# Nexveil 0.67.14

Мелкая чистка страницы «Реверс».

## Что изменилось

- под заголовком «Реверс-мосты» убран пояснительный абзац («Мост — это обратный
  туннель: роутер сам подключается к серверу-порталу…»);
- до этого, в версиях 0.67.12 и 0.67.13, со страницы «Реверс» убраны: общий
  переключатель способа реверса, тексты про «способ задаётся у каждого моста»,
  абзац про цвета мостов и карточка «Как заполнять»; диагностика «что видит
  панель» убрана под спойлер.

## Способ реверса теперь у каждого моста (0.67.12)

Раньше был общий способ реверса, а у моста можно было выбрать «как у роутера».
Из-за этого мост со старым способом молча не попадал в конфиг, когда общий стоял
«новый». Теперь способ задаётся у каждого моста: «старый (по домену)» или
«новый (по тегу)». Если выбранный способ эта сборка xray не умеет, это видно в
списке мостов — «в конфиг не попадёт». При обновлении старое общее значение
переносится в мосты, где способ не был задан.

## Установка

Одной командой в терминале роутера (сама выберет формат пакета и загрузчик):

    M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); U=https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E; if command -v wget >/dev/null 2>&1; then wget -q -O /tmp/xraypanel.$E "$U"; else curl -sL -o /tmp/xraypanel.$E "$U"; fi && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

Или из самой панели: «Статус» → «Обновление панели» → «обновить».

Панель в разработке (бета): от версии к версии что-то меняется. Если что-то не
работает или есть идея — пишите в Issues репозитория.
