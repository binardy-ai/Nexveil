# Nexveil 0.67.4

Первый этап двуязычности: панель теперь умеет русский и английский интерфейс.

## Имя панели: Nexveil

Панель называется **Nexveil** — в шапке сразу видно, что это
«Nexveil · Xray-прокси для роутера», и в заголовке вкладки браузера тоже.
Внутренние имена не менялись: пакет, каталоги (`/usr/lib/xraypanel`,
`/etc/config/xraypanel`), служба и репозиторий остались прежними — так установка,
обновление и уже сохранённые настройки продолжают работать без миграции.

## Два формата пакета и одна команда установки

OpenWrt до 24.10 ставит пакеты через `opkg` (файлы `.ipk`), а с 25.12 пакетный
менеджер уже `apk` (файлы `.apk`) — старые `.ipk` там не ставятся вообще. Теперь
в релизе лежат оба файла:

    xraypanel_0.67.4_all.ipk   — для opkg (23.05, 24.10, ImmortalWrt 23.05)
    xraypanel_0.67.4_all.apk   — для apk (OpenWrt 25.12+)
    xraypanel_all.ipk / xraypanel_all.apk  — то же, но с постоянными именами

В README есть одна универсальная команда: роутер сам смотрит, чем у него
управляются пакеты, скачивает из последнего релиза нужный файл и ставит его.
Обновление из панели тоже выбирает файл по системе.

## Что нового (этап 1)

- **Выбор языка** на странице «Настройки»: «как в браузере (авто)», «русский»,
  «English». В режиме «авто» язык берётся из настроек браузера, по умолчанию —
  русский.
- **Переведён «скелет» интерфейса**: меню (Статус, Серверы, Реверс, Прокси,
  Маршруты, Конфиг, Настройки, Бэкап), заголовки карточек, названия кнопок и
  заголовки столбцов таблиц — 174 строки. Длинные пояснения пока остаются на
  русском: они будут переведены следующими этапами (номер версии при этом
  меняться не будет).
- Строки вынесены в языковые файлы `/usr/lib/xraypanel/lang/ru.sh` и
  `lang/en.sh`; в коде остались короткие ссылки вида `$T_settings`. Такой способ
  не влияет на скорость: подстановка переменных в shell бесплатна, а вес пакета
  вырос всего на ~10 КБ.

## Что нового (этап 2)

- **переведены подписи, списки и подсказки**: поля форм, пункты выпадающих
  списков, всплывающие подсказки, подписи столбцов на узком экране, серые
  пояснения под таблицами, спойлеры, тексты ссылок — 494 новых строки
  (в словаре стало 668);
- **переведена браузерная часть**: «проверяю…», «сохранено», названия режимов
  прозрачного прокси, подсказки конструктора шаблонов, единицы измерения. Строки
  берутся из словаря `window.__xpT`, подстановка — через `__t("ключ")`;
- оформление больше не зависит от языка: правила CSS, привязанные к русским
  подписям столбцов, заменены на языконезависимые;
- в README переписан раздел установки: теперь там два способа — одной командой в
  терминале роутера (панель сама выбирает `.ipk` или `.apk` и ставит файл) и
  скачиванием файла на компьютер с установкой из менеджера программ в
  веб-интерфейсе роутера.

Пока остаются на русском динамические сообщения: заголовки «Новое правило»,
тексты после сохранения («сервер сохранён»), значения в таблицах состояния и
разбор ошибок. Это следующий этап, номер версии из-за этапов не меняется.

## Установка

Одной командой в терминале роутера — она сама определит формат пакета, скачает
из последнего релиза нужный файл и поставит его:

    M=$(command -v apk >/dev/null 2>&1 && echo apk || echo opkg); E=$([ "$M" = apk ] && echo apk || echo ipk); curl -sL -o /tmp/xraypanel.$E https://github.com/binardy-ai/Nexveil/releases/latest/download/xraypanel_all.$E && { [ "$M" = apk ] && apk add --allow-untrusted /tmp/xraypanel.apk || opkg install --force-reinstall /tmp/xraypanel.ipk; }

Или скачать файл на компьютер из раздела **Releases** (`.ipk` — для OpenWrt и
ImmortalWrt до 24.10, `.apk` — для 25.12 и новее) и поставить его из
веб-интерфейса роутера: **Система → Менеджер программ → Загрузить пакет**.

Обновить панель можно и прямо из неё: «Статус» → «Обновление панели» →
«проверить обновление сейчас» → «обновить». Настройки, серверы и правила при
установке и обновлении не трогаются.

Панель в разработке (бета): от версии к версии что-то меняется. Если что-то не
работает или есть идея — пишите в Issues репозитория.
