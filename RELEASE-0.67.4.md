# xraypanel 0.67.4

Первый этап двуязычности: панель теперь умеет русский и английский интерфейс.

## Что нового

- **Выбор языка** на странице «Настройки»: «как в браузере (авто)», «русский»,
  «English». В режиме «авто» язык берётся из настроек браузера, по умолчанию —
  русский.
- **Переведён «скелет» интерфейса**: меню (Статус, Серверы, Реверс, Прокси,
  Маршруты, Конфиг, Настройки, Бэкап), заголовки карточек, названия кнопок и
  заголовки столбцов таблиц — 174 строки. Длинные пояснения пока остаются на
  русском: они будут переведены следующими этапами (номер версии при этом
  меняться не будет).
- Строки вынесены в языковые файлы `/usr/lib/xraypanel/lang/ru.sh` и
  `lang/en.sh`; в коде остались короткие ссылки вида `$T_settings`. Такой способ
  не влияет на скорость: подстановка переменных в shell бесплатна, а вес пакета
  вырос всего на ~10 КБ.

## Установка

    scp xraypanel_0.67.4_all.ipk root@<IP роутера>:/tmp/
    ssh root@<IP роутера> 'opkg install --force-reinstall /tmp/xraypanel_0.67.4_all.ipk'

Или из панели: «Статус» → «Обновление панели» → «проверить обновление сейчас» →
«обновить».
